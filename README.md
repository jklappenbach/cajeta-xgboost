# cajeta-xgboost

A nucleo-native gradient-boosted decision tree (GBDT) library for
[cajeta](https://github.com/jklappenbach/cajeta) that reproduces **XGBoost's
NVIDIA GPU `hist` algorithm bit-for-bit** — on every backend cajeta runs on:
CPU, AMD (Strix Halo), and NVIDIA.

## Why

XGBoost's GPU path is CUDA-first and does not run on AMD APUs like Strix Halo. A
model scored where the reference can't run — and whose numbers therefore *don't
match* the reference — is untrustworthy. cajeta-xgboost's contract is the cure:

- **Bit-exact to the NVIDIA reference.** Given the same inputs and
  hyperparameters, cajeta produces the identical trees and identical predictions,
  to the bit, as reference XGBoost's deterministic GPU algorithm.
- **Cross-backend identity.** The same bits on CPU, AMD, and NVIDIA — so a result
  computed on Strix Halo matches one computed on an NVIDIA box exactly.
- **Determinism is the default and the guarantee.** Any non-deterministic mode is
  opt-in, named in the API, and recorded in model metadata.

## Status

**The CPU phase is complete (0.3.0): bit-exact to the NVIDIA GPU reference
across the full v1 scope.** Every tree, every boosting round, and every
prediction is checked against golden fixtures generated by `xgboost-gpu`
(3.1.2) on NVIDIA, asserted per round / per tree / per node:

- All three objectives — `reg:squarederror`, `binary:logistic`,
  `multi:softprob`/`multi:softmax` — bit-identical **at scale** (20k×50
  synthetics with 5% missing) and on a **real benchmark** (50k×54 UCI
  covertype, 7 classes, 21 trees).
- The device's arithmetic is reproduced where it matters: `expf` via the
  probed `MUFU.EX2` interpolation model, `__fdividef` gain scoring via the
  probed SFU reciprocal table, the device's per-feature argmax and
  min_child_weight gate semantics, signed-zero leaf weights, and the GPU
  quantile-sketch prune arithmetic.
- Raw → cuts → bins → trees → prediction closes bit-exact end to end
  (`GBDT.fit`/`predict`), with the pruned GK sketch included.
- Missing-value default directions, feature importance (`get_score`
  parity), serialization round-trip, and the deterministic-by-default API
  (stochastic knobs refused, non-determinism labeled + recorded).
- `XGBRegressor` conforms to `dev.cajeta.ml`'s estimator protocol, so
  models drive `Pipeline`/`crossValScore` and the ml model-selection
  surface directly.

Next: the GPU phase (U12) — the `cajeta.xpu` histogram kernels with
cross-backend bit-identity, NVIDIA → Strix Halo.

## Build & test

```
./run-tests.sh          # builds the library + cajeta-unit, runs the suite
```

Requires a cajeta toolchain (≥ 0.10.0, which ships `cajeta.nucleo.*`) and a
[cajeta-unit](https://github.com/jklappenbach/cajeta-unit) checkout alongside.
